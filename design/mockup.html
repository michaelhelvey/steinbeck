# On Cutting
Every draft begins **too long**. That is not a failure; it is the material you cut from. It is believed by most writers that the first draft, which is written quickly and without very much attention to the structure of the argument or the rhythm of the sentences, should be revised extensively before anyone sees it.
I *really* think teh problem is simpler then that. Most bad sentences are bad because the writer did not yet know what they meant. The sentence was written before the thought was finished, and so the reader is asked to do the work that the writer avoided.
> The best sentence is the one you never had to explain.
## A small checklist
- Cut every adverb that a stronger verb could replace.
- Read it **out loud**. If you run out of breath, the sentance is too long.
- Look for `is`, `was`, and `were` followed by a past participle.
- Their are always more words to cut.
## Tools
I utilize a small script to run the rules on any draft, see [the source](https://example.com/cut) for details.
```ts const adverbs = /\b\w+ly\b/g; // One match per adverb. Zero when there are none. export function countAdverbs(text: string): number { return text.match(adverbs)?.length ?? 0; } ```
In the end, it is basically just a matter of deleting things until what remains is true, which is honestly harder than it sounds.
